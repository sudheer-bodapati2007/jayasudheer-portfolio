# Bodapati Nohidh Jaya Sudheer — Developer Portfolio

A responsive, single-page developer portfolio built with HTML, CSS, and vanilla JavaScript. It follows the Student Portfolio Website guide and uses resume-supported information only.

## Included
- Responsive desktop, tablet, and mobile layouts
- Midnight Navy design with a working light/dark theme toggle
- Mobile navigation and accessible skip link
- About, skills, project, education, and contact sections
- Links to GitHub, LinkedIn, LeetCode, Warranty Wallet live demo, and repository
- Downloadable updated resume PDF in `assets/`
- Subtle reveal animations with reduced-motion support

## Run locally
No build tools or package installation are needed. Open `index.html` in a browser, or serve the folder with any static web server.

## Deploy to Vercel
1. Create a GitHub repository for this folder and push the files.
2. In Vercel, import that repository.
3. Select **Other** / static site if asked for a framework preset. No build command is required; the output directory is the project root (`.`).
4. Deploy, then open the generated URL and test the page, resume download, mobile navigation, and external links.

You can also deploy this static folder to Netlify or GitHub Pages.

## Content accuracy
The portfolio includes one completed project currently supported by the resume. Certifications, achievements, and work experience are not listed because none were provided. Add future projects only when you have completed them and can explain their implementation.
